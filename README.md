# gearscope.app

Landing page for **Gearscope** — reads your camera's real shutter count, serial number,
lens and firmware straight from a photo file. Free web check runs entirely in your browser;
nothing is uploaded.

Served by GitHub Pages at <https://gearscope.app>.

## Editing

`index.html` is **generated** — do not edit it directly. Change the source in the Gearscope
repo (`core-js/build-demo.mjs`), run `node core-js/build-demo.mjs`, and copy the result here.
`privacy.html` and `support.html` are hand-written and safe to edit in place.
